Embedded home security system

A 4-digit combination lock implemented in ARM assembly on the TI MSP432P401R. Photoresistor-triggered activation, button-driven combination entry, LED status feedback, multi-attempt lockout. Bare-metal: no operating system, no HAL, direct memory-mapped I/O.

What it does

The system sits idle until a photoresistor detects light (a person passing). That triggers entry mode. The user enters a 4-button combination on tactile switches; combination LEDs light to confirm each press. A check button submits the attempt. If correct, a green LED stays on. If incorrect, a red LED lights to indicate the attempt count, and after three failed attempts the system enters an emergency lockout with flashing red LEDs that doesn’t recover until reset.

How it works

The MSP432 was configured at the register level. GPIO directions, pull-up resistors, and pin assignments are written directly to the port configuration registers. No GPIO library, no abstraction layer. The combination check uses a single comparison register accumulated bit-by-bit as each button is pressed, so the final state is one byte compared against the correct combination (0xC1) in a single instruction.

The state machine runs in a tight polling loop: read button state, branch to the appropriate handler, update the comparison register, return to the loop. Each LED has a guard so it can only be lit once per attempt, preventing a held button from passing the check.
